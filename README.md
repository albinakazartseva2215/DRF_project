DRF_project

## Описание

DRF_project это проект платформы для онлайн обучения.

## Запуск проекта
1. Установите Docker, Docker Compose, Redis, Postgres, если они ещё не установлены.
2. [Клонируйте репозиторий](https://github.com/albinakazartseva2215/DRF_project)
2. В терминале, перейдите в директорию проекта.


## Проверка работоспособности

- **Настройте SSH-доступ к вашему серверу**: Сгенерируйте SSH-ключ и добавьте его в GitHub Secrets.
- **Добавьте шаг деплоя в workflow**: Настройте деплой вашего Docker-образа на сервер. Включите шаги для остановки 
старого контейнера и запуска нового с обновленным образом.
Убедитесь, что деплой выполняется только в том случае, если все предыдущие этапы (линтеры, тесты) прошли успешно.
- **Проверьте работу CI/CD-пайплайна**: Сделайте коммит в свой репозиторий и проследите за выполнением всех шагов 
пайплайна в GitHub Actions.
Убедитесь, что пайплайн успешно выполняет все шаги, включая линтинг, тестирование, сборку Docker-образа, 
публикацию и деплой.
- **Исправление ошибок и финализация**: Если какой-либо из шагов не прошел, исправьте ошибки и снова 
запустите пайплайн.
Когда пайплайн выполнится успешно, убедитесь, что ваше приложение работает на сервере, как ожидалось.
